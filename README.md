# TaskTracker v1.3

## Описание
TaskTracker — это консольное приложение на платформе .NET, предназначенное для отслеживания и управления задачами. 

## Используемые технологии
- C#
- .NET 8 SDK
- Git / GitHub

## Требования
Для разработки, сборки и запуска приложения требуется установленный .NET 8.0 SDK.

## Структура проекта
TaskTracker_AuditProject/
├── src/
│   └── TaskTracker/          # Исходный код приложения
├── docs/                     # Документация проекта
├── config/                   # Конфигурационные файлы и шаблоны
├── README.md
├── CHANGELOG.md
└── .gitignore

## Запуск
1. Установите .NET 8 SDK.
2. Откройте терминал в корневой папке проекта.
3. Перейдите в каталог с исходным кодом:
   cd src/TaskTracker
4. Восстановите зависимости:
   dotnet restore
5. Запустите приложение:
   dotnet run

## Основные возможности
- Просмотр списка текущих задач.
