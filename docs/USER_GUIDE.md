# Руководство пользователя TaskTracker 1.3  

## 1. Назначение программы
Приложение TaskTracker предназначено для локального учета и управления списком задач через консольный интерфейс.

## 2. Запуск
Для запуска необходимо перейти в папку `src/TaskTracker` и выполнить команду `dotnet run`.

## 3. Основные возможности
- Просмотр актуального backlog.

## 4. Порядок работы
После запуска программы пользователь взаимодействует с системой через текстовое меню, вводя соответствующие номера команд.

## 5. Ограничения
Приложение является консольным, сохраняет данные локально и требует для работы установленный .NET 8 Runtime.
