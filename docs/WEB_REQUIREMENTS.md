# Требования к будущей веб-версии TaskTracker

## 1. Поддерживаемая среда
Веб-интерфейс должен корректно работать как минимум в Mozilla Firefox и современных Chromium-браузерах (Google Chrome, Microsoft Edge).

## 2. Работа с вкладками
- Пользователь может открыть приложение в нескольких вкладках одновременно без сбоев в работе сессии.
- Основные данные формы создания задачи не должны теряться при случайном закрытии вкладки.
- Состояние данных должно синхронизироваться между вкладками.

## 3. Всплывающие окна
- Критические функции приложения не должны работать через автоматически открываемые окна (pop-up).
- Интерфейсные диалоги должны быть реализованы через встроенные модальные элементы страницы.

## 4. Cookies и авторизация
- Использовать cookies только для хранения токенов авторизации и необходимых параметров сессии.
- Корректно обрабатывать завершение или принудительное удаление пользовательской сессии с перенаправлением на страницу входа.
- Форма входа должна быть совместимой со стандартными менеджерами паролей браузеров за счет применения стандартных тегов form и input.

## 5. Разрешения браузера
- Приложение не должно запрашивать камеру, микрофон или геолокацию без жизненной необходимости.
- Отказ пользователя от предоставления разрешения на браузерные уведомления не должен блокировать основную функциональность системы.
